# Analysis Portfolio
This repository contains examples of analytical work completed by Sylvia Onchaga and is provided as a sample of my coding, statistical analysis, and reproducible research workflow.

## Repository Contents
### 1. Zoetis Mastitis Incidence Analysis
This project demonstrates an epidemiological analysis workflow for estimating disease incidence and identifying risk factors in a cohort study.

Key skills demonstrated:
* Data management and cleaning
* Incidence estimation
* Survival analysis
* Epidemiological methods
* Reproducible research workflows

### 2. Energy Drink Randomized Trial Analysis
This project was completed as part of a doctoral application analytical exercise and evaluates the effect of energy drinks on reaction time and blood sugar levels.

Key skills demonstrated:
* Analysis of experimental data
* Statistical modelling
* Interpretation of results
* Reproducible reporting using R Markdown
* Scientific reporting

## Software
* Stata
* R

The original datasets used in these analyses are not included because they are confidential or subject to data-sharing restrictions. The repository is intended to demonstrate analytical workflows, coding practices, and reporting approaches.
