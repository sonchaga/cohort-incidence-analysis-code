# Energy Drink Randomized Trial Analysis
This project was completed as part of a doctoral application analytical exercise.
The objective was to analyze data from a randomized controlled trial evaluating the effect of energy drinks with varying sugar and caffeine content on reaction time and blood sugar levels.

## Repository Contents
### Analysis Script
* report_onchaga_exercise_2_20231130.Rmd

This R Markdown script contains the complete analytical workflow, including data preparation, statistical analyses, generation of tables, and interpretation of findings.

### Analytical Report
* report_onchaga_exercise_2_20231130.pdf

This report summarizes the study design, statistical methods, results, and interpretation of findings.
